# Cindy Tang Portfolio

A static portfolio built with HTML, CSS, and JavaScript.

## Main files

- `index.html` — homepage
- `style.css` — main portfolio styles
- `script.js` — homepage interactions
- `projects.html` — all-projects page
- `project-navigation-center.html` — featured navigation center project
- `project-wolverine.html` — featured wolverine habitat project
- `butters-domain.html` — interactive Butters page
- `butters-domain.css` — Butters' Domain styling and responsive layout
- `butters-domain.js` — Butters' Domain interactions
- `pet-album.html` — Butters, Pepper, and Cola photo album
- `pet-album.css` — pet album styles
- `resume.pdf` — add resume with this filename

## Project detail pages

The two featured project pages use a simplified layout:
- short intro
- map
- what I did
- key data
- takeaway
- tools
- link to the full PDF

This keeps the pages concise and avoids repeating the same information in multiple cards.

## Project page refinement

The featured project pages now keep the titles smaller and put more visual emphasis on the maps. Supporting text focuses on process, methods, and tools instead of repeating information already visible in the map.
